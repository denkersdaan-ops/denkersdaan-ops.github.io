Front-end programming

Here are some of my projects I've worked I did on recently for websites.

First Period

All of my first period projects for front-end were made in my website classes. We used HTML and CSS. I never made a website before so this was all new for me.
Between FRONT-END and BACK-END I believe that Front-end is a bit easier. I think that is because it involves a lot more design than logic.

Flex Sites

This is where I learned how to use Flex. We learned this through some sites, like FlexboxDefense and FlexboxFroggy.

This was the first time I worked with Flexbox so it was a learning experience. I think it helped me understand how to create flexible layouts. This came in handy later for the other projects I made.

Flexbox

After we learned flex we made a small project to test our knowledge of Flexbox. This is the result of that project. We needed to place boxes in certain places using Flexbox.

After I learned the basics of Flexbox, I was able to apply it more effectively in this project. It helped me understand how to align and distribute space among items in a container. I was able to finish the project in a short time, so that was nice.

Pink Goose

This was the final project for the first period. We got a pre-made design and had to make it work with HTML and CSS. I believe this project helped me understand the importance of design in web development.

This project taught me a lot about translating designs into functional web pages. It emphasized the importance of attention to detail and consistency in styling. It also taught me that reusing the same CSS parts can save time and effort. Something that I'm using now for this Portfolio.

Flappy Bird

This was a personal project where I recreated the classic Flappy Bird game using HTML, CSS and JavaScript. I did this in my personal time and finished it in the first 3 days of the study.

I have been programming since I was 9, so I learned most of my things through self-study and practice. when I started this study I already had a good foundation, which helped me a lot. So to see if my skills were up to par, I decided to recreate the Flappy Bird game. Now that the first period is over, I can say that I'm far above most of my classmates, mainly when it comes to back-end programming.

Back-end programming

Here are some of my projects I've worked I did on recently for my programming classes.

First Period

I had some back-end experience before I went to study at ROC. When I was 9 I started with some small unity project. With this I learned some C#. I stopped using unity when I saw a post about you needing to pay for the new versions. In our programming lessons we use Java. This is very close to C#, so it wasn't hard to learn. In the first period we learned the basics of programming, like what a variable is, but I already knew this, so the first period was a bit boring. So I made some project in those lessons.

Mastermind

Mastermind was the end project of the first period.

This project didn't take long for me. I got a version with numbers working instead of colors on day one, and the rest like adding the colors did not take any more time.

Azurill

Azurill was the project I worked on when I was bored in my programing lessens. Desktop goose was its inspiration.

The inspiration for this project was Desktop goose; an app where u get a goose on your screen that adds memes, text or dirt to it. So I made a version of it, but for the pokemon Azurill. I chose this pokemon because Maril, the evolution of Azurill, is my favorite pokemon, since it is the first known Pikachu clone.

Find the odd one out

Here in this project the goal is to find some dogs between a large group of randomly generated humans.

I also made this because I was bored in my programming lessons. Here I made my own panels and windows. I did this because you needed to do that if you wanted transparency to work and this game works around transparency. The window in the image can be moved, which is how you try and find the dog. The location of all the people is random, and the hair, cap, clothes and stripes are all randomly generated with their colors.

Second Period

The second period was boring because we didn't do a lot. We just made Mastermind better, but most of the things we needed to do to improve it I had already implemented, so I started to learn C++. My goal is to make a 2D game engine. What I mean by this is just the basics, so no physics engine just yet.

Mastermind

Mastermind was again the end project of the second period, but now we needed to add more features to it. We learned more about arrays, randoms and functions. Most of these things I had already implemented in my first version, so I just needed to add a few adjustments.

This project wasn't very hard because I already had most of the features implemented. The reason why I didn't do so much this period was because I remade the project in C++, but I still needed to do it in Java, since not everyone had a C++ compiler and a part of my grade was based on someone else looking at my work.
